# ChatGPT Prompt Library

This README describes a simple static site for hosting Human Factors Cast's ChatGPT prompts. The prompts live in .txt files.

## What this is

A tiny prompt library you can:

- Browse in a web UI
- Search by title, text, or tags
- Filter by tag
- Copy prompts with one click

Everything is plain HTML, CSS, and JavaScript. No build step.
